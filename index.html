Mandelbrot Atlas

An explorable map of the Mandelbrot set. Zoom from the whole set down to a copy of it a trillion times smaller.

Open the atlas (opens in a new tab) Works on mobile too

  • Shallow views render in real time on the graphics card, in a WebGL2 shader running every pixel in parallel.
  • Past about ×10,000, 32-bit floats run out of digits. Rendering hands off to Web Workers doing 64-bit math on every CPU core, streaming a rough preview first and the full image after.
  • Trace any point’s orbit, watch its Julia set update as you move, take a guided dive, and share any view by its link.

Built with WebGL2 and GLSL, Web Workers and JavaScript, in one HTML file with no libraries.

CountSift

Find what you’re not billing for.

A free tool for managed IT service providers. It compares what they bill against the devices and licenses they actually manage, and lists every gap.

Visit countsift.com (opens in a new tab) Free, and files never leave the browser

  • Reads CSV exports from billing systems, device-monitoring tools and Microsoft 365 license reports, then maps their columns.
  • Matches customers and products across files despite different spellings, without confusing plan tiers like Business Basic and Business Premium.
  • Flags under-billing, over-billing and wrong plans, and estimates what each gap is worth from the prices already in the billing export.

Built with JavaScript, HTML and CSS, with no backend. Hosted on Cloudflare Pages.
