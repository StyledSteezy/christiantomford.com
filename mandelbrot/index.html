Mandelbrot Atlas

Every coastline on this map is drawn by one rule, z ↦ z² + c, repeated. Scroll or pinch into any edge. It never runs out of detail.

The rule

Pick a point c on the plane. Start with z = 0 and apply z ↦ z² + c over and over. If z stays small forever, c belongs to the set: the solid region. If z runs off to infinity, c is outside, and its color shows how quickly it escaped.

Why it stops at 2

Once |z| passes 2 it can never come back, so the program stops counting there. The number of steps that took is the point’s escape time.

Smooth color

Whole-number step counts paint the plane in hard bands. Subtracting log₂ log |z| turns the count into a continuous value, so colors blend. Contour lines mark where the whole-number count changes.

Julia sets

Freeze c and vary the starting point instead, and you get a Julia set. Every point has one. For points inside the Mandelbrot set it is one connected piece; outside, it breaks apart into dust. The Mandelbrot set is a map of which Julia sets hold together.

Relatives

Change the rule and the coastline changes. Raise the power for Multibrot sets, take absolute values each step for the Burning Ship, or mirror z each step for the Tricorn.

How it’s built

  • Shallow views run in a WebGL2 fragment shader. Every pixel iterates in parallel on the graphics card, in 32-bit floats.
  • 32-bit floats carry about 7 significant digits, which run out near ×10,000. Past that, rendering moves to a pool of Web Workers iterating in 64-bit doubles (about 16 digits), good to roughly ×10¹².
  • Workers stream a coarse preview, then the full image, center first. Results land in a float texture that the GPU colors, so palette changes and color cycling stay instant.
  • Points inside the set stop early, using closed-form tests for the main cardioid and the largest bulb plus cycle detection on the orbit.
  • The view lives in the URL, so any place you find can be shared. One HTML file, no libraries.
